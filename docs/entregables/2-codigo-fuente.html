4. Cómo compilar y publicar

4.1 Interfaz web

Requiere Node 22 o más reciente. Desde front-end/:

Comandos de la interfaz
ComandoQué hace
npm installInstala las dependencias.
npm run dev:caseta · npm run dev:adminAbre la app con datos simulados del contrato, sin servidor; ?rol= cambia de usuario de prueba.
npm run buildRevisa los tipos y genera dist/app-caseta.html, dist/portal-admin.html y dist/registro-alumno.html.

4.2 Servidor en Apps Script

  1. Compilar la interfaz (npm run build) y copiar dist/app-caseta.html y dist/portal-admin.html a apps-script/.
  2. Crear el proyecto ligado a una hoja nueva: npx @google/clasp create --type sheets --rootDir apps-script.
  3. Subir el código con npx @google/clasp push y publicar con npx @google/clasp create-deployment. El manifiesto ya indica Ejecutar como: yo y Acceso: cualquier usuario con cuenta de Google.
  4. Al primer uso, el servidor crea las hojas, las tres casetas y da de alta al propietario como Administrador (también se puede ejecutar setup() desde el editor).
  5. La liga /exec abre la app de caseta; con ?app=admin, el portal.

4.3 Componentes complementarios y pruebas

  • Backend y analizador: docker compose up --build en appsheet-backend/ (variables en .env.example).
  • Pruebas automatizadas: go test -race ./... en appsheet-backend/ y pytest en appsheet-backend/analizador/.
  • Los README de cada carpeta tienen las instrucciones completas.
