2. Instrucciones de acceso para el jurado

2.1 Requisitos

  • Un navegador actualizado (Chrome, Edge o Firefox), en celular para la app de caseta y en computadora para el portal.
  • Una cuenta de Google (por ejemplo, Gmail). El sistema no usa contraseñas propias: Google pide iniciar sesión y el sistema identifica la cuenta.

2.2 Cuentas para evaluar

No hace falta registro previo. En este prototipo, la primera vez que una cuenta de Google entra, el sistema la da de alta como Administrador, con acceso a todas las funciones. Para probar los roles de Guardia o Supervisor, en Administración → Usuarios del sistema se edita la cuenta y se le cambia el rol.

Las cuentas distintas a la del propietario aparecen como «Invitado …», porque Google no comparte su correo con una aplicación publicada desde una cuenta personal.

Con varias cuentas de Google abiertas en el mismo navegador, Apps Script puede fallar al cargar. Usen una ventana de incógnito con una sola cuenta.

2.4 Demostración sin cuenta de Google

Si no es posible entrar con una cuenta de Google, las demostraciones de la caseta y del portal muestran la misma interfaz con datos ficticios y el aviso «Demostración · datos ficticios». Para cambiar de usuario de prueba se agrega ?rol= a la liga: ADMIN, SUPERVISOR, GUARDIA, ROTATIVO (guardia sin caseta fija) o NOREG (cuenta sin acceso). Por ejemplo: https://hackathonfrontend.452111.xyz/admin?rol=SUPERVISOR.

El manual de usuario describe cada pantalla con capturas.
